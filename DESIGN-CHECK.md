# Self-check — answer all eight before showing a screen

One line each. Do not skip one for being obvious.

1. **What is this screen for?** One sentence. Two means it is two screens.
2. **Is that the first thing on it?** If the screen knows an answer, the answer is the headline.
3. **What is the single action?** Name the primary button. Is it the fix, or a retry that cannot work?
4. **Word count on first view?** State the number.
5. **Any string repeated?** Quote the repeat and what you deleted.
6. **Any raw server text, id, HTTP code or field name visible?** They belong behind a support code.
7. **Does every warning have a button?** Name them.
8. **What did you cut?** Three things. Nothing cut means it is not designed yet.
