# SEC-101 critique (written before the code) - verdict at the end

(a) Assumptions checked
- docHash = sha256(SCHEME:value), stored in identity_documents.value_hash: TRUE (routes/identity-docs.js:427-433, stored :319-322).
- Aadhaar is a 10^12 space so a dump recovers it offline: TRUE (pattern /^[0-9]{12}$/, :101). It also has no secret in it at all.
- Scope = store:false schemes: only AADHAAR has store:false (:100-107, "the ONLY entry with it"). PAN, VOTER_ID, DL are store:true (value_enc under VAULT_ENC_KEY) so their ciphertext is the guarded copy; their unkeyed hash is also enumerable (PAN is structured) -> DPO question, out of scope.
- Callers: PHONE/EMAIL only in lib/identity-auth.js:106,116 and routes/keys.js:448; readers lib/iddoc-verify.js:149,163; routes/keys.js:430. No reader looks up AADHAAR by hash. The only SQL that touches value_hash for another scheme is the PUT upsert (conflict key is (identity_id, scheme), not the hash).
- value_hash never reaches an answer: TRUE (PUT returns scheme/value_masked/status/submitted_by; GET reads value_enc only, :351). No finding.
- Column varchar(64): HMAC-SHA256 hex is 64: TRUE.
- Today without a key: store:true schemes answer 503 VAULT_ENC_UNCONFIGURED (:258-266); Aadhaar skips that check and is stored with the bare hash.

(b) Conflicts: none. Reuses lib/vaultcrypto.js getKey (seams: no hkdf, no keyed hash exists). One function, no new setting. PHONE/EMAIL stay unkeyed because sign-in matches them by recomputing the hash (lib/identity-auth.js) and a keyed hash would orphan every verified contact.

(c) Simpler: a keyed hash with the vault key directly. Rejected: one key for two jobs; HKDF with a context label keeps them separate at no cost.

(d) Risks: legacy rows cannot be re-hashed (value not stored), so a legacy match is kept for in-scope schemes until a count says zero (owner call). Rotating VAULT_ENC_KEY changes every keyed hash (same as it already strands value_enc) -> note in the PR. No migration. Behaviour change: with no key Aadhaar is now refused (503), as every other scheme already is.

(e) VERDICT: BUILD AS BRIEFED.
